# One Patient, Many Channels: code and aggregate results

Code and aggregate results for the paper *"One Patient, Many Channels: Accounting for
Re-Identification Risk in Clinical Retrieval-Augmented Generation"*
by Pavlo Zamroz, Sandrine Vaton and Kassem Kallas.

> **Status.** This repository is being prepared. The code and the aggregate results will be added
> when the paper is submitted, together with the licence and citation metadata. Until then it holds
> only this file.

## What this repository will contain

- `clinbench/`: the benchmark used in the paper, a per-patient risk ledger with the attacks and
  defences it accounts for.
- `configs/`: one configuration file for every run reported in the paper.
- `results/`: the aggregate result files behind every table and figure.
- `scripts/` and `tests/`: the scripts that build the tables and figures, and the unit tests.

## What this repository does not contain, and will not

**No patient data, and no derived data at the patient or record level.** The synthetic notes are
generated by the code, and PMC-Patients is a public dataset. For the credentialed datasets, only
aggregate results are published: one row per experimental condition, never per person or per note.
